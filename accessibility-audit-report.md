# Accessibility Audit Report

**Project:** Student Activity Management Portal  
**Date:** 23 November 2026

## Accessibility features included

| Requirement | Implementation |
|---|---|
| Page language | `lang="en"` is used in the HTML element. |
| Browser metadata | Character set, viewport, description and page title are included. |
| Semantic HTML | Header, nav, main, section, article, aside and footer are used. |
| Heading structure | H1 is used for the main title, followed by H2 and H3 headings. |
| Form labels | Each text field, dropdown and textarea has a label. |
| Radio buttons | Radio buttons are grouped using fieldset and legend. |
| Checkboxes | Checkboxes are grouped using fieldset and legend. |
| Keyboard access | Normal form controls and links can be accessed using the keyboard. |
| Focus visibility | CSS adds an outline when links and form controls receive focus. |
| Form feedback | A status message is announced when the form is submitted. |

## Lighthouse / WAVE audit

The page should be opened in a browser and checked using Lighthouse or WAVE before submission.

For Lighthouse:
1. Open the webpage in Google Chrome.
2. Press F12 and open the Lighthouse tab.
3. Select Accessibility and run the audit.
4. Save a screenshot of the actual result.

**Note:** No Lighthouse or WAVE score is claimed in this report because an external audit has not yet been run.
