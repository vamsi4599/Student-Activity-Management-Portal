# Student Activity Management Portal

## Files
- index.html: Webpage structure and student registration form.
- style.css: Basic page styling.
- script.js: Displays a message when the form is submitted.
- accessibility-audit-report.md: Accessibility checks for this webpage.

## How to run
1. Open this folder in Visual Studio Code.
2. Open index.html in a browser, or use Live Server.
3. Fill in the registration form and click Register.

Note: This is a front-end lab task. The form displays a confirmation message but does not store data in a database.
